## Логи для администраторов

В личном чате с ботом откройте `/menu` → «📋 Логи» или отправьте `/logs`.
Раздел доступен только Telegram ID из списка администраторов. Есть обновление
и фильтр ошибок; время записей — UTC. Логи содержат причины отказа входа,
статусы отправки офферов/анализа, ошибки Telegram API и сервера, ID запросов.
Токены, подписанные данные Telegram, тексты сообщений и скриншоты не записываются.

Последние 500 событий сохраняются в `DATA_DIR/diagnostics.json` (по умолчанию
`data/diagnostics.json`). Для сохранения после перезапуска/деплоя подключите
постоянный Railway Volume и укажите его путь в `DATA_DIR`. События также выводятся
в stdout, доступный в логах сервиса Railway. Отдельный контейнер не нужен.

При `TELEGRAM_POLLING=true` раздел работает сразу. В режиме webhook задайте
`TELEGRAM_WEBHOOK_SECRET` и зарегистрируйте webhook с тем же `secret_token`;
запросы без подтверждённого источника не могут читать логи. Подписанный Mini App
также предоставляет админам `GET /api/admin/logs?errors=true`.

## Vision-анализ

Приложение принимает до 28 типизированных скриншотов RAID и заполняет калькулятор через OpenAI Responses API. Для включения распознавания задайте `OPENAI_API_KEY` в Railway. Модель можно изменить переменной `OPENAI_VISION_MODEL`.

MVP веб-приложения для ориентировочной оценки аккаунтов Raid: Shadow Legends. Пользователь вводит 14 показателей аккаунта и получает диапазон стоимости, оптимальную цену и расшифровку факторов.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev:web
```

Откройте `http://localhost:5173`.

## Проверка

```powershell
npm.cmd run check
npm.cmd run build
```

Расчёт выполняется локально в `src/App.tsx`; данные пользователя не отправляются на сервер. Текущие коэффициенты — стартовая гипотеза, которую нужно калибровать по выборке реальных сделок.

Сервис независимый и не связан с Plarium Global Ltd.

## Railway

Проект готов к публикации на Railway. Сборка выполняется командой `npm run build`, запуск — `npm start`, проверка состояния доступна по адресу `/api/health`.
